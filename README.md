# SkyFiles — نسخه اولیه PWA

## اجرای محلی
برای تست، فایل‌ها را در یک وب‌سرور محلی اجرا کنید؛ باز کردن مستقیم `index.html` برای نصب PWA کافی نیست.
با Python:
```bash
python -m http.server 8000
```
سپس در همان دستگاه به `http://localhost:8000` بروید.

## انتشار رایگان
می‌توانید این پوشه را در یک مخزن GitHub قرار دهید و از GitHub Pages برای میزبانی رایگان استفاده کنید. PWA برای نصب به HTTPS یا localhost نیاز دارد.

## دسترسی فایل‌ها و محدودیت‌ها
- در مرورگرهای سازگار، دکمه «انتخاب پوشه» از File System Access API استفاده می‌کند و دسترسی فقط پس از انتخاب و تأیید کاربر داده می‌شود.
- پشتیبانی انتخاب پوشه و عملیات نوشتن/حذف بین مرورگرها و نسخه‌های اندروید متفاوت است. اگر پشتیبانی نشود، برنامه به انتخاب چندفایلی/پوشه‌ای به‌عنوان حالت جایگزین می‌رود؛ در این حالت فایل‌های اصلی قابل تغییر یا حذف نیستند.
- فایل‌ها به هیچ سروری آپلود نمی‌شوند.
- شناسایی تکراری‌ها در این نسخه بر اساس نام و اندازه است؛ برای تأیید قطعی باید محتوای فایل‌ها هش شود و این قابلیت در نسخه بعدی اضافه می‌شود.
- انتقال و کپی بین پوشه‌ها، پخش‌کننده داخلی و پیش‌نمایش رسانه در این نسخه اولیه هنوز پیاده‌سازی نشده‌اند.
- فایل‌های انتخابی در حالت جایگزین پس از رفرش دوباره باید انتخاب شوند.
